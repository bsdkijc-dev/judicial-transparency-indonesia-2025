# Judicial Transparency Indonesia — FY 2025 Mahkamah Agung RI Financial Reconciliation

Structured, auditable, Google Sheets-ready (UTF-8 CSV, pure numeric fields) and Markdown dataset extracted from *Laporan Keuangan Mahkamah Agung Republik Indonesia Tahun 2025 (Audited)* (signed 8 Mei 2026).

- `data/` — Six primary analytical tabs (`Summary_KPIs`, `LRA_Budget_Execution`, `Court_Escrows_Uang_Titipan`, `Grants_and_ThirdParty_Aid`, `State_Losses_TP_TGR_BPK`, `Capex_KDP_Projects`).
- `reconciliation/` — `financial_reconciliation_exceptions_2025.csv` and domain reconciliation reports.
- `reports/` — Executive audit summary, data quality assessment, and FY 2024–2025 comparability analysis.
- `metadata/` — Data dictionary, source inventory, accounting framework, and verification protocol.
